# Stellar Suspects

Браузерная multiplayer-игра в жанре social deduction до 10 игроков. Экипаж чинит корабль «Skyward», а среди игроков прячутся предатели. Название, карта, персонажи и графика оригинальные.

**Стек:** React 19 · Vite 8 · TypeScript 6 · Phaser 3.90 · Socket.IO 4.8 · Express 5 · Zod 4 · Prisma 7 + PostgreSQL · Vitest 5

## Что умеет игра

- Меню, создание комнаты, вход по 6-символьному коду, лобби с выбором имени и цвета, настройки хоста
- Карта корабля из Tiled: Cafeteria, Electrical, MedBay, Reactor, Navigation, Storage, Security; коллизии и точки появления берутся из файла карты
- Движение на WASD или стрелках с анимациями и камерой. Клиент предсказывает движение, сервер его подтверждает
- Роли «экипаж» и «предатель» (1–2 предателя) раздаются случайно; чужие роли игроку не отправляются
- 14 заданий трёх типов мини-игр и общая полоса прогресса
- Устранение с проверкой дистанции и перезарядки, тела, отчёт о теле, экстренная кнопка
- Саботаж: отключение света (темнота у экипажа) и авария реактора (обратный отсчёт, чинить нужно 2 панели)
- Собрания с чатом, тайное голосование, пропуск, ничья, исключение игрока, показ роли исключённого (настраивается)
- Условия победы: все задания выполнены, все предатели выброшены, предателей столько же, сколько экипажа, реактор взорвался
- Переподключение после перезагрузки страницы, грейс-период при обрыве связи, передача роли хоста
- Необязательный аккаунт: регистрация, вход, профиль, статистика и история матчей (PostgreSQL)

## Быстрый старт (Windows 11 / PowerShell)

```powershell
node -v          # v24.x LTS (минимум 22.12)
npm install
Copy-Item server/.env.example server/.env
npm run dev
```

Откройте http://localhost:5173. Чтобы поиграть одному, создайте комнату и запустите ботов в другом терминале:

```powershell
npm run bots -- <КОД_КОМНАТЫ> 3
```

Подробнее: [docs/SETUP_WINDOWS.md](docs/SETUP_WINDOWS.md).

## Скрипты (из корня)

| Команда                                       | Что делает                                                                 |
| --------------------------------------------- | -------------------------------------------------------------------------- |
| `npm run dev`                                 | shared (watch) + server (:3001) + client (:5173)                           |
| `npm run bots -- CODE [N] [--still] [--hunt]` | N ботов для тестирования (`--hunt`: боты-предатели устраняют и саботируют) |
| `npm run build` / `npm start`                 | production-сборка и запуск (сервер отдаёт и клиент)                        |
| `npm run check`                               | format + lint + typecheck + тесты: запускать перед PR                      |
| `npm run db:migrate`                          | применить миграции Prisma к PostgreSQL (dev)                               |
| `npm run map:generate`                        | заново сгенерировать карту Skyward и тайлсет                               |
| `docker compose up --build`                   | PostgreSQL + игра в Docker                                                 |

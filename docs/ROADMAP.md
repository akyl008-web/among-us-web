## Параллельные задачи на этап 2–4

- **Game Dev:** `PlayerController` (WASD, нормализация диагонали), анимации idle/walk, камера follow.
- **UI/UX:** спрайт-лист персонажа (SVG/PNG, 10 цветов через tint), тайлсет 32×32, черновик карты в Tiled.
- **Frontend:** экраны MainMenu / CreateRoom / JoinRoom / Lobby (пока на моках), роутинг по состоянию.
- **Multiplayer:** спецификация событий `room:*` и `player:move` в shared + схемы + тесты.
- **Team Lead:** `RoomManager` и `Match` state machine на сервере (чистые классы + unit-тесты).
